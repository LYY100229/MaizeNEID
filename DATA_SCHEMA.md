# MaizeNEID data schema

## Current release

- Dataset: `cytoplasmic_mature_v1`
- Selection table: `megadock/union_g2_e3_n3/megadock_selected_union.tsv`
- Selection policy: global top 2% ∪ Effector top 3 ∪ NLR top 3
- Displayed records: 911 pairs, all included in the current AF-Multimer input set
- Effector inputs: 127 supplied Fusarium candidates
- Maize receptor inputs: 164 proteins
- Available evidence: MEGADOCK only

`interactions.json` contains only the selected records, never the unfiltered scored universe. `effectors.json` and `nlrs.json` include the exact FASTA sequence used for each input so the browser can build a download package for checked pairs. NLR classes are mapped from the integrated NLR annotation table; no taxonomy filtering is applied to the user-supplied Fusarium dataset.

AF-Multimer and AlphaFold 3 fields are intentionally unavailable until completed results are imported. No complex structure, contact residue, hydrogen-bond, or experimental-validation values are generated by this release.
